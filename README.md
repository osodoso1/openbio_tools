🧬 openbio_tools
🚀 Engineered for high-throughput molecular biology workflows. This library streamlines everything from complex genomic analysis to downstream qPCR data coordination, giving bioinformaticians and wet-lab scientists the ultimate automation advantage.

Currently under active development to transform repetitive, manual data curation tasks into seamless, reproducible workflows.

🛠️ The Toolkit
gDNA to qPCR request to asana

The Mission: Bridge the gap between wet-lab execution and project management.

How it works: Automatically processes and maps genomic DNA datasets into structured qPCR sample requests, pushing them directly to Asana to orchestrate flawless downstream testing hand-offs.

plate_map_generator

The Mission: Ditch the manual Excel grid headache.

How it works: Instantly generates custom plate layout maps for laboratory assays based on your variable strain and sample counts—pre-formatted perfectly into standard 10x5 and 3x5 structural arrays.

16s_closest_relatives

The Mission: Accelerated taxonomic identification.

How it works: Rapidly queries sequence databases to isolate, analyze, and return the closest phylogenetic relatives of a target strain using its 16S rRNA fingerprint.

filtercontigs

The Mission: Precision sequence QC.

How it works: A dynamic filtering script that slices through assembly data, isolating and extracting contigs that meet your strict, user-defined length thresholds.

🔓 Open-Source & Free: Built by community demand, for the community. Clone it, run it, and supercharge your pipeline.
